# Nix package icons (#209)

## Fixed
- Linux: the flake package installs the packaged
  `com.twayblade.desktop.desktop` (Exec pointed at the store path), the 512 px
  icon in `share/icons/hicolor` and the metainfo, instead of a hand-written
  `twayblade.desktop` with no icon. The entry's name matches the window's
  app ID (Wayland `app_id`, X11 `WM_CLASS`), so menus, docks and Alt-Tab
  show the icon.
- macOS: the bundle gets `Twayblade.icns`.
- The package source now includes `packaging/` and `assets/`.

## Verified
- `nix eval` of the package for x86_64-linux and aarch64-darwin.
- `nix build .#twayblade` on aarch64-darwin: the bundle contains
  `Contents/Resources/Twayblade.icns`.
- All rc.4 release packages checked for their icon (DMG/zip, deb, rpm,
  AppImage, tar.gz, MSI tables, Windows exe resources, AUR PKGBUILD).

## Not verified
- A Linux `nix build` and the icon on GNOME/KDE after installing it.
