# One app icon on every platform

## Built

- The icon from #159 (orange `(*)` / `</|\>` mark on black) is the app icon
  everywhere, replacing the earlier Linux and Windows icon from #95:
  - macOS: `assets/Twayblade.icns` in the bundle (`CFBundleIconFile`),
    copied by `macos/build.sh`; the same files and lines as #159, so the two
    merge cleanly.
  - Linux: `packaging/icons/com.twayblade.desktop.png` (512 px) for the deb,
    rpm, AUR package, tarball and AppImage. The source is raster, so the
    scalable SVG is gone; packages install the 512 px PNG in hicolor.
  - Windows: `packaging/icons/twayblade.ico` (16–256 px) for the exe, MSI and
    shortcuts.
- `packaging/icons/render.sh` regenerates the PNG and ICO from
  `assets/twayblade-icon-transparent.png`.
- The README starts with the icon and now describes what Twayblade does and
  how to install it on each system.

## Verified

- macOS bundle built with the icon (`Contents/Resources/Twayblade.icns`,
  `CFBundleIconFile`) and opened as an offline preview.
- ICO holds 16, 24, 32, 48, 64, 128 and 256 px images.

## Not verified

- Linux and Windows packages with the new icon (CI builds them on main).
