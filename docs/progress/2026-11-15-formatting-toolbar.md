# Formatting toolbar

Formatting toolbar (2026-11-15, `feature/formatting-toolbar`, issue #39): the
composer's toolbar row has Bold, Italic, Code, Link and Quote buttons on its left
that apply the same Markdown edits as the shortcuts and return focus to the
field; tooltips show the shortcuts. The thread composer keeps shortcuts only.
Verified by a capture, an offline click test and compilation. There is no list
button yet, and nothing was checked on a physical keyboard or with VoiceOver.
